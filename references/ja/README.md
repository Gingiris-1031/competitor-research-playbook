## 三、SNSチャネル解剖

### 3.1 トラフィック源の判定

SimilarWebで主要トラフィック源を特定し、重点チャネルを深掘り。**そのチャネルで強い競合を優先分析する。**

### 3.2 Twitter/X アカウントマトリクス

| アカウントタイプ | 分析ポイント |
|-|-|
| **公式** | 投稿頻度/リズム/トーン、コンテンツカテゴリ比率 |
| **創業者アカウント** | 公式との差別化度 |
| **Dev Relアカウント** | BD/エコシステム連携コンテンツ |
| **KOLアカウント** | フェーズごとのインフルエンサー連携 |

### 3.3 コンテンツ投稿リズム（4フェーズ）

```
クローズドベータ → ワイドリリース → 定常運用 → ローンチウィーク
```

### 3.4 プラットフォーム間戦略比較

| 項目 | X/Twitter | YouTube | LinkedIn | TikTok |
|-|-|-|-|-|
| ポジショニング | バイラル点火 | ユーザーアクティベーション | エンタープライズ獲得 | ブレイクアウトリーチ |
| 頻度 | 毎日1-3件 | 毎週1-3件 | 毎週1-2件 | 高頻度 |

## 四、グロースフライホイール分析法

### 4.1 フライホイール6段階スコアリング

| 段階 | 核心的問い |
|-|-|
| アクティベーション | 「Aha Moment」をどう生む？ |
| リファラル | プロダクト内にバイラルメカニクスがある？ |
| アクイジション | 潜在ユーザーをどう引き付ける？ |
| リテンション | コミュニティへの帰属感をどう構築？ |
| レベニュー | 無料→有料への転換パスは？ |
| プロダクト最適化 | フィードバックがどうイテレーションを駆動？ |

### 4.2 強い/弱いフライホイールの判断基準

| 指標 | 強いフライホイール | 弱いフライホイール |
|-|-|-|
| リテンション | Discord DAU高い、UGC継続 | ユーザーが早期に離脱 |
| 口コミ | ユーザーストーリーの体系的拡散 | 増幅メカニズムなし |
| マネタイズ | コンバージョンのトリガーが明確 | パスが曖昧 |
| 持続性 | プロダクト↔コミュニティのフィードバックループ | 外部広告に依存 |

## 五、伝播ノード分析法

### 5.1 4フェーズ伝播モデル

| フェーズ | タイムライン | キーイベント |
|-|-|-|
| 内部点火 | ローンチ後数時間 | チーム一斉発信 |
| エコシステム触媒 | 1-2日 | パートナーのエンドースメント |
| KOL爆発 | 2-3日 | トップKOLがナラティブを定義 |
| 広域浸透 | 数週間 | 多言語ユーザーの参加 |

### 5.2 コンテンツ効果ランキング（データ検証済み）

| # | タイプ | インパクト |
|-|-|-|
| 🥇 | ビジュアルデモ（動画/GIF） | 最大のインパクト |
| 🥈 | リアルユーザーの成功事例 | 最も信頼性が高い |
| 🥉 | 競合比較コンテンツ | ディスカッションを喚起 |
| 4 | 定量データの可視化 | ソーシャルカレンシー |
| 5 | 機能アナウンス | リーチが狭い |

### 5.3 KOL特定基準

| タイプ | シグナル |
|-|-|

| トピックスターター | コメント欄での深い議論 |
