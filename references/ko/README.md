## 1. 경쟁사 조사 핵심 프레임워크

### 1.1 4단계 조사법

| 단계 | 내용 | 산출물 |
|-|-|-|
| **Step 1** | 경쟁사 **웹사이트** 각 버전 단계 해부 | 사이트 진화 경로, 밸류 프로포지션 변천, 고객 획득 구조 |
| **Step 2** | 경쟁사 **소셜 미디어** 콘텐츠 전략 해부 | 채널별 콘텐츠 분류, 게시 리듬, KOL 협업 모델 |
| **Step 3** | **디렉토리/애그리게이터** 분석 (필요시) | 트래픽 소스, 경쟁사 광고 배치 |
| **Step 4** | **유료 광고** 해부 (필요시) | 광고 채널, 크리에이티브 전략, 트래픽 어트리뷰션 |

### 1.2 도구 스택

| 도구 | 용도 |
|-|-|
| [Wayback Machine](https://web.archive.org/) | 과거 웹사이트 스냅샷 조회 |
| [SimilarWeb](https://www.similarweb.com/) | 트래픽 소스 분석, 채널 분포 |
| [Semrush](https://www.semrush.com/) | SEO & 광고 인텔리전스 |

## 3. 소셜 미디어 채널 해부

### 3.1 트래픽 소스 판단

SimilarWeb으로 주요 트래픽 소스를 먼저 파악한 뒤, 핵심 채널을 심층 분석합니다. **해당 채널에서 잘하는 경쟁사를 우선 분석하세요.**

### 3.2 Twitter/X 계정 매트릭스

| 계정 유형 | 분석 포인트 |
|-|-|
| **공식 계정** | 게시 빈도/리듬/톤, 콘텐츠 카테고리 비율 |
| **파운더 계정** | 공식과의 차별화 정도 |
| **Dev Rel 계정** | BD/생태계 파트너십 콘텐츠 |
| **KOL 계정** | 단계별 인플루언서 협업 |

### 3.3 콘텐츠 게시 리듬 (4단계)

```
클로즈드 베타 → 와이드 릴리스 → 정상 운영 → 런칭 위크
```

### 3.4 크로스 플랫폼 전략 비교

| 항목 | X/Twitter | YouTube | LinkedIn | TikTok |
|-|-|-|-|-|
| 포지셔닝 | 바이럴 점화 | 유저 활성화 | 엔터프라이즈 획득 | 브레이크아웃 리치 |
| 빈도 | 매일 1-3건 | 주 1-3건 | 주 1-2건 | 고빈도 |

## 4. 그로스 플라이휠 분석법

### 4.1 플라이휠 6단계 스코어링

| 단계 | 핵심 질문 |
|-|-|
| 활성화(Activation) | "Aha Moment"를 어떻게 유도하는가? |
| 추천(Referral) | 프로덕트 내 바이럴 메커니즘이 있는가? |
| 획득(Acquisition) | 잠재 유저를 어떻게 끌어오는가? |
| 유지(Retention) | 커뮤니티 소속감을 어떻게 구축하는가? |
| 수익(Revenue) | 무료 → 유료 전환 경로는? |
| 프로덕트 최적화 | 피드백이 어떻게 이터레이션을 추진하는가? |

### 4.2 강한/약한 플라이휠 신호

| 지표 | 강한 플라이휠 | 약한 플라이휠 |
|-|-|-|
| 리텐션 | Discord DAU 높음, UGC 지속 | 유저 이탈 빠름 |
| 입소문 | 체계적 유저 스토리 확산 | 증폭 메커니즘 없음 |
| 수익화 | 전환 트리거 명확 | 경로 불분명 |
| 지속성 | 프로덕트 ↔ 커뮤니티 피드백 루프 | 외부 광고에 의존 |

## 5. 전파 노드 분석법

### 5.1 4단계 전파 모델

| 단계 | 타임라인 | 핵심 이벤트 |
|-|-|-|
| 내부 점화 | 런칭 후 수시간 | 팀 일제히 포스팅 |
| 생태계 촉매 | 1-2일 | 파트너 지지 선언 |
| KOL 폭발 | 2-3일 | 탑 KOL이 내러티브 정의 |
| 광역 침투 | 수주간 | 다국어 유저 참여 |

### 5.2 콘텐츠 효과 순위 (데이터 검증)

| # | 유형 | 임팩트 |
|-|-|-|
| 🥇 | 비주얼 데모 (동영상/GIF) | 최고 임팩트 |
| 🥈 | 실제 유저 성공 사례 | 가장 신뢰도 높음 |
| 🥉 | 경쟁사 비교 콘텐츠 | 토론 유발 |
| 4 | 정량 데이터 시각화 | 소셜 커런시 |
| 5 | 기능 공지 | 리치 좁음 |

### 5.3 KOL 식별 기준

| 유형 | 시그널 |
|-|-|
| 트래픽 킹 | 단일 포스트 > 10만 노출 |
| 토픽 스타터 | 댓글에서 깊은 토론 |
| 마인드셋 시프터 | "앞으로 이것만 쓸 거야" |

## 6. X/Twitter 심층 분석

### 6.1 검색 구문

```
from:[Handle] since:YYYY-MM-DD until:YYYY-MM-DD -filter:retweets lang:en
"[제품명]" OR "[도메인]" -from:[공식] since:YYYY-MM-DD -filter:retweets -filter:replies
```

### 6.2 바이럴 포스트 해부

| 항목 | 분석 |
|-|-|
| 훅 | 어떤 각도에서 이야기하는가? |
| 너겟 | 공유하고 싶게 만드는 포인트는? |
| 감정 | 경탄 / 호기심 / FOMO? |
| 비주얼 | 어떤 이해 비용을 줄이는가? |

## 7. 종합 인사이트 프레임워크

### 5차원 분석

| 차원 | 산출물 |
|-|-|
| 시장 포지셔닝 | 세그멘테이션, 페르소나, 차별화 |
| 비즈니스 모델 | 프라이싱, 플라이휠 |
| 실행 전략 | AARRR, 콘텐츠 캘린더 |
| 재사용 가능한 전술 | 택틱 + 적용 범위 |
| 리스크 | 식별 + 조기 경고 지표 |

### 셀프 체크리스트

```
□ 3개 버전 마일스톤을 모두 커버했는가?
□ 주요 소셜 채널을 전부 해부했는가?
□ 플라이휠 강점과 약점을 식별했는가?
□ 전파 데이터로 뒷받침했는가?
□ 재사용 가능한 전술 + 적용 범위를 추출했는가?
□ 리스크 + 조기 경고 지표를 식별했는가?
□ ICP가 3개 이상의 세그먼트를 커버하는가?
□ 프라이싱에 업그레이드 경로 분석이 있는가?
□ 실행 가능한 전술 제안이 있는가?
```
