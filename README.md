## English

### What Is This?

Your competitor just blew up and you have no idea how. Tear down their website? Track their social? Map their flywheel? The honest answer is: all of it, in a fixed order. This playbook is the complete SOP — a 4-step research framework (website teardown → social media → traffic sources → ad spend) with a template for every step, so competitive analysis produces a strategy input instead of a folder of screenshots.

### What's Inside

- **4-step research framework** — website teardown → social channels → traffic sources → ad spend
- **3-version website evolution analysis** — V1 / Beta / Launch snapshots via Wayback Machine, with a per-version recording template (value prop, page structure, SEO moves, community channels, integrations)
- **X/Twitter propagation chain mapping** — 4-phase model + single-post teardown template
- **Growth flywheel 6-stage scoring** — Activation → Referral → Acquisition → Retention → Revenue → Product
- **KOL identification framework** — Traffic King / Topic Starter / Mindset Shifter
- **Content effectiveness ranking** — validated ordering: Visual Demo > User Story > Competitor Comparison
- **ICP deep-analysis template + freemium pricing teardown**
- **Complete self-check checklist** before you call the research done

## 中文

### 这是什么？

你的竞品刚刚爆了，你完全不知道他们怎么做到的。拆官网？盯社媒？画飞轮？诚实的答案是：都要做，且有固定顺序。这份 SOP 提供完整的四步调研法（官网拆解 → 社媒渠道 → 流量来源 → 广告投放），每一步都配模板，让竞品分析产出的是战略输入，而不是一堆截图。基于 150+ AI 创业公司竞品分析实战，含 Lovable 完整案例（发布日 4.3M views / 229K impressions）。

### 内容清单

- **四步调研法**——官网拆解 → 社媒内容策略 → 流量来源 → 投放拆分
- **官网三版本演进分析**——用 Wayback Machine 还原 V1 / Beta / Launch 三个节点，逐版本记录 Value Prop、页面结构、SEO 动作、社区渠道、集成生态
- **X/Twitter 传播链路还原**——四阶段模型 + 单帖拆解模板
- **增长飞轮六阶段评分**——Activation → Referral → Acquisition → Retention → Revenue → Product
- **KOL 识别框架**——流量王 / 话题发起者 / 心智转变者三类角色
- **内容有效性排序**（实测：可视化 Demo > 用户故事 > 竞品对比）
- **ICP 深度分析模板 + Freemium 定价拆解**
- **交付前自查清单**
